# 記帳牧場 Fortune Farm

台灣風格的記帳養成遊戲：每記一筆消費，牧場地圖就會誕生對應動物；相同類型、相同等級的動物可以合併升級。

## 玩法

| 類型 | 動物 |
|------|------|
| 餐飲 | 🐷 豬 |
| 交通 | 🐴 馬 |
| 購物 | 🐑 羊 |
| 娛樂 | 🐔 雞 |
| 居家 | 🐄 牛 |
| 學習 | 🐰 兔 |
| 醫療 | 🐱 貓 |
| 其他 | 🐶 狗 |

- 點兩隻**同類型、同等級**的動物 → 按「合併升級」
- 等級：幼崽 → 成長 → 成年 → 精英 → 傳說（最高 Lv.5）
- 資料存在瀏覽器 `localStorage`

## 啟動

```bash
npm install
npm run dev
```

開啟終端機顯示的本機網址即可遊玩。
